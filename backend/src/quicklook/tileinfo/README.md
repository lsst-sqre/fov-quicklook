# TileInfo

LSST Camの焦点面にはCCDが多数敷き詰められている。
この焦点面をとある大きさの正方形で分割したものをタイルと呼ぶ。

タイルは規則正しく格子状に敷き詰められており、CCDの配置とタイルの配置は独立している。
`TileInfo`はとあるタイルに対して作られるインスタンスで、どのタイルかを指定するとそのタイルとオーバーラップするCCDの情報を提供する。

タイルにはレベルという概念がある。レベル0は最も細かいタイルで、レベルが1上がるごとにタイルの一辺の長さが2倍になる。

焦点面上のccdの配置は`ccd-info.json`に記載されており、`TileInfo`はこの情報をもとにタイルとオーバーラップするCCDを計算する。
