子孫プロセスから順に（親プロセスの方はバックトレースをダンプするハンドラが設定されていないかもしれない）SIGUSR1を送信して./logにバックトレースを書き出して原因を調べてください。

書き出す前に./logをtruncateすると出力が混ざらないので良いでしょう。

現在のプロセスツリーも記録しておくべきでしょう。

まずはバックトレースが書き出されるのを確認してください。
