# FOV-Quicklook Frontend

This application communicates with Frontend to display FOV-Quicklook data running in a browser.

## Features

* Display list of visits
  * Filtering and pagination

* Display visit details
  * Visit information
  * List data contained in visit
  * Display tile data


## Flow for Displaying Visit Details

1. Select a visit to display details from the visit list view
1. Wait for the visit status to become ready
